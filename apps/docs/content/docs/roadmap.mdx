The following roadmap outlines the planned development stages for **OProgress**. These steps are subject to change based on community feedback and technological advancements.

## Done

* **Modern Engine Architecture**  
  * [x] Rewrite the state engine on top of `emittor` for a reactive, singleton-style API.

* **Framework Integration Packages**  
  * [x] Create the React package (`@oprogress/react`)  
  * [x] Create the Next.js package (`@oprogress/next`)  

* **Styling & Accessibility**  
  * [x] Enable easy customization of the progress bar using CSS variables.  
  * [x] Replace ARIA roles with CSS class selectors for better flexibility and compatibility.  
  *(See: [ARIA Techniques](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/ARIA_Techniques))*

* [x] Add comprehensive documentation for each package.
* [x] Add a testing suite for the core and React packages.

## Next steps

- **Testing**  
  * [ ] Add tests for the Next.js package.

- **Continuous Improvement**  
  Refine packages and features according to community needs and feedback.

- **Explore New Features**  
  Identify and implement advanced features to further enhance the user experience (additional animations, advanced configurations, etc.).
