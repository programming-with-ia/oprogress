---
title: done()
description: progress.done() method
---

The `done()` method is used to stop the progress bar.

## Usage

```js
progress.done();
```

## Typing

```ts
progress.done(force?: boolean): void;
```

## Parameters

| Name  | Type    | Description                                                        |
|-------|---------|--------------------------------------------------------------------|
| force | boolean | Force the progress bar to finish immediately, even if not started. |
