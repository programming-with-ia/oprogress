---
title: start()
description: progress.start() method
---

The `start()` method is used to start the progress bar.

## Usage

```js
progress.start();
```

## Typing

```ts
progress.start(startPosition?: number, delay?: number): void;
```

## Parameters

| Name | Type | Description |
|------|------|-------------|
| startPosition | number | The starting percentage value (0-1). |
| delay | number | Delay in ms before starting the progress bar. |
