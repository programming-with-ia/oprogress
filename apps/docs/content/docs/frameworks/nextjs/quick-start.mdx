## Installation

To install OProgress, run the following command:

<Tabs groupId="packageManager" items={['npm', 'pnpm', 'yarn', 'bun']} persist>
  <Tab value="npm">```bash npm install @oprogress/next ```</Tab>
  <Tab value="pnpm">```bash pnpm add @oprogress/next ```</Tab>
  <Tab value="yarn">```bash yarn add @oprogress/next ```</Tab>
  <Tab value="bun">```bash bun add @oprogress/next ```</Tab>
</Tabs>

Now you are ready to use OProgress in your Next.js application!

## Import

### App Directory

Import into your `/app/layout(.js/.jsx/.ts/.tsx)` folder.

```tsx
import { OProgress } from '@oprogress/next';
```

### Pages Directory

Import into your `/pages/_app(.js/.jsx/.ts/.tsx)` folder.

```tsx
import { OProgress } from '@oprogress/next';
```

## Usage

```tsx
<OProgress />
```

## Example

### App Directory

First approach in a use client layout.

```tsx title="app/layout.tsx"
'use client';

import { OProgress } from '@oprogress/next';

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>
        <OProgress 
          height="4px"
          color="#fffd00"
          shallowRouting
        />
        {children}
      </body>
    </html>
  );
}
```

Second approach wrap in a use client Providers component. (Recommended)

Create a Providers component to wrap your application with all the components requiring 'use client', such as OProgress or your different contexts...

```tsx title="app/providers.tsx"
'use client';

import { OProgress } from '@oprogress/next';

const Providers = ({ children }: { children: React.ReactNode }) => {
  return (
    <>
      <OProgress 
        height="4px"
        color="#fffd00"
        shallowRouting
      />
      {children}
    </>
  );
};

export default Providers;
```

Then wrap your application with the Providers component.

### Pages Directory

```tsx title="pages/_app.tsx"
import type { AppProps } from 'next/app';
import { OProgress } from '@oprogress/next';

export default function App({ Component, pageProps }: AppProps) {
  return (
    <>
      <OProgress
        height="4px"
        color="#fffd00"
        shallowRouting
      />
      <Component {...pageProps} />
    </>
  );
}
```
