## Installation

To install OProgress, run the following command:

<Tabs groupId="packageManager" items={['npm', 'pnpm', 'yarn', 'bun']} persist>
  <Tab value="npm">```bash npm install @oprogress/react ```</Tab>
  <Tab value="pnpm">```bash pnpm add @oprogress/react ```</Tab>
  <Tab value="yarn">```bash yarn add @oprogress/react ```</Tab>
  <Tab value="bun">```bash bun add @oprogress/react ```</Tab>
</Tabs>

Now you are ready to use OProgress in your React application!

## Import

```tsx
import { ProgressBar } from '@oprogress/react';
```

## Usage

```tsx
<ProgressBar />
```

## Example

```tsx title="src/index.tsx"
import React from 'react';
import ReactDOM from 'react-dom/client';
import './index.css';
import App from './App';
import { ProgressBar } from '@oprogress/react';

const root = ReactDOM.createRoot(
  document.getElementById('root') as HTMLElement,
);
root.render(
  <React.StrictMode>
    <ProgressBar height="3px" color="#29d" />
    <App />
  </React.StrictMode>,
);
```

```tsx title="src/App.tsx"
import { useProgress, progress } from '@oprogress/react';

function App() {
  const [state, { start, stop, pause, resume }] = useProgress();

  return (
    <div className="App">
      <p>Progress Active: {state.isStarted ? "Yes" : "No"}</p>
      
      {/* Control using the hook methods */}
      <button onClick={start}>Start</button>
      <button onClick={stop}>Stop</button>
      <button onClick={pause}>Pause</button>
      <button onClick={resume}>Resume</button>
      
      {/* Or control directly using the progress instance! */}
      <button onClick={() => progress.start()}>Start (Direct)</button>
      <button onClick={() => progress.stop()}>Stop (Direct)</button>
    </div>
  );
}

export default App;
```
