## Installation

### Node.js

To install OProgress, run the following command:

<Tabs groupId="packageManager" items={['npm', 'pnpm', 'yarn', 'bun']} persist>
  <Tab value="npm">```bash npm install @oprogress/core ```</Tab>
  <Tab value="pnpm">```bash pnpm add @oprogress/core ```</Tab>
  <Tab value="yarn">```bash yarn add @oprogress/core ```</Tab>
  <Tab value="bun">```bash bun add @oprogress/core ```</Tab>
</Tabs>

### CDN

Use **unpkg**:

- JS: https://unpkg.com/@oprogress/core/dist/index.global.js
- ESM: https://unpkg.com/@oprogress/core/dist/index.js
- CSS: https://unpkg.com/@oprogress/core/dist/index.css

Use **jsDelivr**:

- JS: https://cdn.jsdelivr.net/npm/@oprogress/core/dist/index.global.js
- ESM: https://cdn.jsdelivr.net/npm/@oprogress/core/dist/index.js
- CSS: https://cdn.jsdelivr.net/npm/@oprogress/core/dist/index.css
