---
title: set()
description: progress.set() method
---

The `set()` method is used to set the progress bar to a specific percentage.

## Usage

```js
progress.set(0.5);
```

## Typing

```ts
progress.set(n: number): void;
```

## Parameters

| Name | Type   | Description          |
|------|--------|----------------------|
| n    | number | The percentage value between 0 and 1 |
