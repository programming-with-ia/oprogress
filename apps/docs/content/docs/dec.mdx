---
title: dec()
description: progress.dec() method
---

The `dec()` method is used to decrement the progress bar by a specific percentage.

## Usage

```js
progress.dec(0.2);
```

## Typing

```ts
progress.dec(amount: number): void;
```

## Parameters

| Name   | Type   | Description          |
|--------|--------|----------------------|
| amount | number | The percentage value between 0 and 1 |
