---
title: inc()
description: progress.inc() method
---

The `inc()` method is used to increment the progress bar by a specific percentage.

## Usage

```js
progress.inc(0.2);
```

## Typing

```ts
progress.inc(amount: number): void;
```

## Parameters

| Name   | Type   | Description          |
|--------|--------|----------------------|
| amount | number | The percentage value between 0 and 1 |
